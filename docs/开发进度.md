## M3 完成情况（2026-10-18）

**后端**

- 模型：`underwriting_rule`（条件 JSON + 动作 + 启停，product_id 空为通用）、`underwriting_result`（AUTO/MANUAL/RECONSIDER 三来源 + 复核留痕字段，M3 仅用 AUTO）。
- 规则引擎（`app/rules/engine.py`）：条件子命中（风险题答"是"/病史关键词/家族关键词/年龄上下限/保额下限，任一命中即触发）；内置严重度映射（拒保>延期>除外>加费>标体）取最严重结论，**未采用技术方案中的 priority 配置字段**（动作枚举本身表达严重度，简化配置）。
- 流转策略：拒保/延期直接生效；否则 体检 > 转人工 > 自动结论；无命中默认标体。评估幂等（仅处理 AUTO_UNDERWRITING 状态）。
- 触发方式：`settings.use_celery=False`（默认）提交后同步评估；Celery 任务 `auto_underwrite` 骨架就位，接 Redis 后置 True 切异步。
- admin 接口：`GET/POST /admin/rules`、`PUT /admin/rules/{id}`；规则入参校验（加费须比例、除外须描述、延期须月数）。
- 申请详情接口返回已生效结论（result 字段）。

**前端**

- admin 核保规则配置页：条件表单化（风险题多选、关键词逗号分隔、年龄/保额范围）、动作参数动态展示、启停。
- 客户申请详情页展示核保结论卡片（结论类型/加费比例/除外责任/延期时长/理由）。
- 新增结论类型与规则动作中文映射。

## M4 完成情况（2026-10-18）

**后端**

- `application` 新增 `auto_advice` JSON 列（迁移 `106f32723105`）：智能评估无论是否出结论都留存命中规则快照，供核保员参考"为何转人工"。
- 人工核保接口（`/underwriting`，核保员/主管角色）：
  - `GET /tasks?status=` 案件列表（含客户姓名，可按状态筛选）；
  - `GET /tasks/{id}` 案件详情（投保资料 + 答卷 + 评估快照 + 最新人工结论记录）；
  - `POST /tasks/{id}/conclusion` 出具结论（仅 MANUAL_REQUIRED 状态，参数校验同规则口径），申请单 → REVIEWING；
  - `GET /reviews` 待复核列表（主管）；`POST /reviews/{id}/approve` 通过 → 结论 is_final、申请单 DECIDED；`POST /reviews/{id}/return` 退回（意见必填）→ 结论留痕 RETURNED、申请单回 MANUAL_REQUIRED，可重新出具新结论。
- 复核针对结论记录（result_id），退回后旧结论不删除，重新提交产生新记录。
- 客户详情接口在复核通过前 result 为 null（人工结论不对客户可见直至生效），通过后正常展示。

**前端**

- 核保员：核保待办列表（状态页签）、案件处理页（评估命中规则、上次结论与退回意见、五类结论表单按类型显示参数）。
- 主管：复核中心（待复核列表、通过/退回对话框）、案件查看入口。
- 菜单按角色更新：核保员→核保待办；主管→核保待办+复核中心。

**测试**：后端 42 用例全部通过（新增 12 个 M4 用例）。

## M5 完成情况（2026-10-18）

**后端**

- 模型：`exam_center`、`exam_item`（字典，admin 维护）、`exam_order`（项目 ID 快照保证历史完整）、`exam_item_result`，迁移 `e24170bd4a87 exam` 已应用。
- 体检单闭环：核保员创建（`EXAM_REQUIRED`/`MANUAL_REQUIRED` 案件可建，创建后锁定待体检；同一案件不允许并发未完成的体检单）→ 机构录入逐项结果 + 总结论（限本机构，项目必须属于本单清单）→ 案件回 `AUTO_UNDERWRITING` 重评 → 体检单 `DONE`。
- **重评防循环**：体检回流重评跳过体检类规则（`from_exam=True`），避免"年龄≥50 要求体检"类规则在体检后再次触发形成死循环。
- admin 字典接口：机构 CRUD、体检项目 CRUD（含启停）。
- 案件详情接口补充 `exam_orders`（含结果明细），核保员可参考体检资料。
- 初始化脚本：预置"演示体检中心"并关联 `examcenter01` 账号。

**前端**

- 核保员案件页：体检单列表（机构/状态/逐项结果/总结论）+ 创建体检单对话框（选机构、勾选项目）。
- 体检机构：体检录入页（本机构单据列表、逐项录入结果值/异常标记/备注、总结论）。
- admin：体检机构管理、体检项目管理页。

**测试**：后端 52 用例全部通过（新增 10 个 M5 用例）。

## M6 完成情况（2026-10-18）
